\# uptime-checker



API kecil yang memeriksa daftar URL secara berkala, menyimpan riwayat di PostgreSQL,

dan menyediakan /health, /status, /metrics. Project latihan DevOps end-to-end.



\## Milestone

\- \[ ] M0 Git workflow (branch, PR, rebase, reflog)

\- \[ ] M1 Aplikasi, test, Dockerfile multi-stage, Compose

\- \[ ] M2 CI (lint, test, build, scan, push ke GHCR)

\- \[ ] M3 Ansible dan secrets

\- \[ ] M4 CD dan rollback otomatis

\- \[ ] M5 Dokumentasi, runbook, demo
